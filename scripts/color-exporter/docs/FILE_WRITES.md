# Запись файлов и границы отката

Расчёт всех выбранных палитр завершается до вызова записи. Ошибка структуры Figma, цвета, идентификаторов или прежнего JSON не оставляет записанной части результата.

Локальное чтение допускает только пути `styles/colors_*.json`. Папка `styles` должна быть настоящей папкой, целевой путь — отсутствовать или быть обычным файлом. Символические ссылки не читаются; неблокирующее открытие не позволяет зависнуть при подмене файла именованным каналом.

Перед записью сохраняются содержимое, права и признаки версии каждого локального файла. Локальная команда также сверяет текст с основой расчёта. В GitHub Actions основа расчёта взята из основной ветки, поэтому снимок текущей служебной ветки собирается отдельно.

## Замена и восстановление

Во временной папке `styles/.color-exporter-*` сначала подготавливаются все новые файлы и резервные копии прежних. Для существующих файлов сохраняются права; новые создаются с режимом `0644`. Неизменившийся файл не переписывается.

Перед каждой заменой повторно проверяются версия и текст. Существующий путь заменяется атомарным `rename`. Новый путь создаётся через `link`, который завершится ошибкой, если кто-то уже занял это имя.

При перехваченной ошибке уже выполненные собственные замены откатываются в обратном порядке. Прежде чем восстановить файл, проверяется, что его не изменил другой процесс. Если безопасный откат невозможен, выдаётся составная ошибка и сохраняется временная папка с резервными копиями; её путь указан в сообщении. При успехе и полном откате временные данные удаляются.

## Что эта защита не гарантирует

Атомарность относится к замене одного пути. Весь набор файлов не переключается одновременно; остановка процесса, отключение питания или сбой системы между заменами могут оставить частичный результат. Журнала восстановления после перезапуска нет.

Проверки выявляют ряд конкурентных изменений, но не обеспечивают блокировку против произвольного параллельного редактора. Для запуска с записью нужна отдельная рабочая копия репозитория. Если сообщён неполный откат, сохраните указанную папку и разберите различия до повторного запуска.

Git-проверки и восстановление исчезнувших страниц — отдельный этап [GitHub Actions](GITHUB_ACTIONS.md). Ошибка Git или GitHub после файловой записи может оставить локальные изменения; она не откатывается файловой транзакцией.
