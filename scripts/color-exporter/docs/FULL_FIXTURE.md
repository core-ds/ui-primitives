# Полный регрессионный слепок

## Зачем он нужен

Маленький тест удобно читает человек, но он не доказывает, что реальный алгоритм сохранил все десять JSON. Полный слепок проверяет это отдельно от сети и тарифа Figma.

Проверка обязательна: она не пропускается при отсутствии `FIGMA_TOKEN`.

## Что лежит в папке

```text
tests/fixtures/full/
├── figma-sanitized.json
├── manifest.json
└── repository/
    └── styles/
        ├── colors_bluetint.json
        ├── colors_brand.json
        └── ... ещё восемь файлов
```

`repository` устроен как маленький `ui-primitives`. Поэтому тот же `runPalettes`, который работает в GitHub Actions, запускается на нём без специальной тестовой ветки в коде.

## Что остаётся от Figma

Только поля, которые читает рабочий алгоритм:

- `document.children`;
- тип и имя страницы, секции, фрейма и прямоугольника;
- заливки, RGB, прозрачность и обезличенный признак связи со стилем или переменной;
- только тип и имя `empty`: остальные свойства такого узла рабочий алгоритм не читает и слепок не сохраняет.

Не сохраняются:

- настоящие идентификаторы узлов, стилей и переменных;
- пользователи;
- дата изменения и версия;
- ссылки и миниатюры;
- история документа;
- содержимое исходных переменных;
- токен Figma;
- полное необработанное тело REST.

Тест отдельно обходит слепок и отклоняет закрытые поля, если они случайно появились.

## Три источника

Все команды ниже выполняются из корня `ui-primitives`. Команда `colors:fixture:update` сама указывает папку экспортёра для размещения слепка.

### `live`

Основной режим. Генератор один раз загружает Color Exporter `JGR9GpDXUneyYHfDdb7BDT` через Figma REST, сразу оставляет только нужные поля, заменяет идентификаторы привязок фиксированными обезличенными маркерами и пишет результат.

```bash
npm run colors:fixture:update -- \
  --repo-root "/путь/к/ui-primitives" \
  --source live
```

`FIGMA_TOKEN` читается только из окружения. Генератор не печатает и не записывает его.

### `snapshot`

Подходит для локального полного ответа `GET /v1/files/JGR9GpDXUneyYHfDdb7BDT`:

```bash
npm run colors:fixture:update -- \
  --repo-root "/путь/к/ui-primitives" \
  --source snapshot \
  --figma-json "/путь/к/полному-ответу.json"
```

Исходный файл остаётся вне слепка. В папку попадает только обезличенная копия.

### `normalized-json`

Служебный режим первоначального создания. Он берёт активные ожидаемые токены и восстанавливает минимальную допустимую раскладку. Устаревшие токены остаются только в ожидаемых JSON, потому что их уже нет в Figma.

Обратное восстановление не кодирует слеши подчёркиваниями. Оно сначала проверяет путь из поля `figma` без изменений, затем варианты с режимом переменной `light/` или `dark/`; допустимым считается только один вариант, который одновременно воспроизводит исходные `key` и `figma`. Режим токена `static_` уже находится в сохранённом пути.

Этот режим проверяет преобразование и байты результата, но не доказывает состояние живой Figma. Для обычного обновления следует использовать `live`.

## Защита от неверного слепка

Генератор собирает новый слепок в отдельной временной папке рядом с `tests/fixtures/full` и запускает на нём все выбранные палитры в режиме `check`. Выбор обязан быть непустым; каждая выбранная страница должна присутствовать в снимке и результатах проверки. Если хотя бы один ожидаемый JSON отличается хотя бы одним байтом, команда завершается ошибкой, сохраняя прежний слепок.

Только после успешной проверки прежний каталог переносится в резервную папку, а новый занимает его место. При ошибке установки прежний каталог восстанавливается. Если восстановление также невозможно, резервная копия остаётся на диске, а ошибка сообщает её точный путь. Остановка процесса или отключение питания между переименованиями не обеспечивают автоматического восстановления.

Параметр `--output-root` обязан указывать на путь с окончанием `tests/fixtures/full`. Ссылки вместо этих папок или файлов слепка запрещены. Существующий каталог разрешено заменять только при согласованной структуре: манифест версии 1, соответствующие ему страницы, папка `repository/styles` и перечисленные JSON. Посторонние файлы и несогласованная структура останавливают обновление до замены; произвольный каталог с похожим именем не удаляется.

Текущий манифест ожидает:

- 10 палитр;
- 2057 активных токенов;
- 232 устаревших токена.

Текущий слепок создан из нормализованных JSON, поэтому в нём нет чисто визуальных `empty`: JSON не хранит такие узлы. Универсальное игнорирование `empty` отдельно проверяется модульными сценариями с разным количеством и положением заглушек.

`full-regression.test.mts` затем повторяет проверку в обычном наборе тестов, копирует маленький репозиторий во временную папку, выполняет запись и повторно сравнивает все десять файлов побайтно.

## Когда обновлять

Слепок обновляется осознанно, когда согласованно изменились Figma и ожидаемые JSON либо подключён состав палитр. Обычный запуск синхронизации не переписывает тестовые ожидания автоматически: иначе ошибка алгоритма могла бы сама узаконить свой результат.
