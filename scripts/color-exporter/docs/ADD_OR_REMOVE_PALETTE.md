# Добавление и отключение набора

Состав экспорта определяется страницами Figma, а не перечнем файлов в репозитории. Списка исключений нет.

## Стандартный набор

Добавьте в Color Exporter страницу `colors_<название_набора>.json` с деревом из [общего формата](FIGMA_FORMAT.md). Если специального модуля нет, автоматически применяются стандартные правила. Страница `colors_new_palette.json` создаст `styles/colors_new_palette.json`; отдельная регистрация и исходный файл для неё не нужны.

Сначала выполните локальный расчёт с `--check` на сохранённом ответе REST. Проверьте ключи, значения и список устаревших токенов. Новая страница без прежнего JSON рассчитывается от пустого объекта.

## Особые правила

Если набор отличается от общего формата, добавьте один файл `src/palettes/<название_набора>.mts`. Имя берётся из страницы без `colors_` и `.json`, с сохранением подчёркиваний. Модуль экспортирует объект `Rule`; проверка TypeScript выполняется через `satisfies Rule`.

Доступные настройки `Rule` описаны в [src/palettes/README.md](../src/palettes/README.md). Указывайте только отличия от общих правил. Добавьте проверку характерного допустимого и недопустимого случая в `tests/core.test.mts` и короткую карточку в `docs/palettes/`.

Удаление модуля при сохранённой странице переводит набор на стандартные правила. Оно не отключает экспорт. Команды `test:colors` и `sync:colors` перед запуском очищают прежнюю сборку экспортёра через `build:colors`; удалённый модуль не остаётся активным в `dist/color-exporter`.

## Отключение и возвращение

Удалите страницу или переименуйте её так, чтобы имя не соответствовало экспортному формату. Локальный запуск перестанет читать и менять соответствующий JSON. Опубликованный JSON автоматически не удаляется.

В GitHub Actions незавершённые изменения исчезнувшей страницы возвращаются к точному состоянию основной ветки. Если файл был создан только в служебной ветке, он удаляется из неё. После слияния запроса на слияние прежний опубликованный файл остаётся в основной ветке. Подробности — в [жизненном цикле ветки](GITHUB_ACTIONS.md).

Чтобы вернуть набор, восстановите экспортную страницу с прежним именем. Токены, снова появившиеся в Figma, возвращаются в активную часть; остальные остаются устаревшими. Удаление опубликованного JSON — отдельное решение, которое экспортёр не выполняет.
