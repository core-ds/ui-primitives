# Monochrome

Страница `colors_monochrome.json`; [модуль](../../src/palettes/monochrome.mts).

Динамические секции: `light/monochrome-black`, `light/monochrome-white` и такие же секции режима `dark`; у них допускается `_inverted`. Статические секции — `static_monochrome-black` и `static_monochrome-white`, без `_inverted`.

Имя фрейма состоит только из цифр. Настоящее состояние — только `default`.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
