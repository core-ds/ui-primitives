# Go

## Где находится набор

- страница Figma: `colors_go.json`;
- файл в коде: `styles/colors_go.json`;
- модуль: `src/palettes/go.mts`.

## Допустимая раскладка

Разрешены только три секции:

- `light/go` — светлый режим переменной Figma и семья `go`;
- `dark/go` — тёмный режим переменной Figma и семья `go`;
- `static_go` — режим токена `static`, записанный в имени переменной.

Имя фрейма состоит из строчных латинских букв, цифр и дефисов. После безусловного игнорирования любого числа `empty` в каждом фрейме должен остаться ровно один настоящий `default`.

Новый фрейм внутри одной из трёх секций экспортируется общей формулой без ручного списка токенов.

## Алгоритм полей JSON

Go полностью использует [стандартный алгоритм всех пяти полей](../TOKEN_FIELDS.md) без отличий. Режим переменной `light/` или `dark/` остаётся в ключе и `web`, но удаляется из `figma`; режим токена `static_` сохраняется во всех этих полях.

## Динамический пример

```text
секция: dark/go
фрейм:  lilac

key   = dark_go_lilac
figma = go/lilac
web   = --color-dark-go-lilac
alias = goColorLilac
```

Префикс режима сохраняется в JSON-ключе и CSS-имени, но не дублируется в пути Figma.

## Статический пример

```text
секция: static_go
фрейм:  lime

key   = static_go_lime
figma = static_go/lime
web   = --color-static-go-lime
alias = staticGoColorLime
```
