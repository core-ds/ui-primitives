# X5

## Где находится набор

- страница Figma: `colors_x5.json`;
- файл в коде: `styles/colors_x5.json`;
- модуль: `src/palettes/x5.mts`.

## Допустимая раскладка

Разрешена только секция `static/brand`. Она целиком совпадает с путём цветового стиля Figma: первый сегмент не является режимом переменной Figma и не удаляется. Имя фрейма состоит из строчных латинских букв, цифр и дефисов. После безусловного игнорирования любого числа `empty` каждый фрейм содержит ровно один настоящий `default`; состояния взаимодействия не разрешены.

Прямоугольник обязан быть связан с цветовой переменной или цветовым стилем. В обоих случаях REST также отдаёт числовое значение единственной `SOLID`-заливки. Ручная заливка и любая дополнительная, в том числе скрытая, заливка запрещены.

## Алгоритм полей JSON

X5 использует [стандартный алгоритм всех пяти полей](../TOKEN_FIELDS.md) с одним отличием при разборе секции: имя `static/brand` сохраняется целиком и не теряет первый сегмент. Для ключа `/` стандартно становится `_`; `rgba`, `hex`, `web`, `alias`, порядок полей и сортировка не отличаются.

## Особенность пути Figma

Имя секции уже совпадает с опубликованным путём стиля. Модуль читает его целиком:

```text
секция: static/brand
фрейм:  primary

key   = static_brand_primary
figma = static/brand/primary
web   = --color-static-brand-primary
alias = staticBrandColorPrimary
```

Стабильный путь строится непосредственно из проверенного имени секции: `static/brand/secondary`.

## Порядок токенов

Активные токены сортируются по полному JSON-ключу тем же общим алгоритмом, что и остальные наборы. Поэтому текущий порядок равен `orange`, `primary`, `secondary`, а новый допустимый токен автоматически занимает своё алфавитное место. Устаревшие токены находятся в отдельном отсортированном хвосте.
