# X5

Страница `colors_x5.json`; [модуль](../../src/palettes/x5.mts).

Дополнительно к общим секциям принимается `static/<семейство>`. Префикс `static/` сохраняется в `figma`, а `static` — в `alias`. Семейство может содержать вложенные части и `_inverted`; имена токенов и состояния подчиняются общим правилам.

Для фрейма `primary` получаются ключ `static_brand_primary`, `figma` — `static/brand/primary`, `alias` — `staticBrandColorPrimary`.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
