# Отличия наборов

Все наборы используют [общий алгоритм](../FIGMA_FORMAT.md). Отдельные модули нужны только для двух отличий:

- [SuperApp](superapp.md): сохранение прежнего `alias` при актуальном имени Figma.
- [X5](x5.md): статический префикс `static/`.

Состав семейств, наличие инверсии и состояний не являются исключениями. Для их добавления по общим правилам не нужны изменения кода или карточки набора. Краткие объяснения с примерами — в [инструкции](../instructions/02-bundle-exceptions.md).

Неизвестная стандартная страница экспортируется автоматически. [Добавление и отключение](../ADD_OR_REMOVE_PALETTE.md).
