# Promo

Страница `colors_promo.json`; [модуль](../../src/palettes/promo.mts).

В режимах `light` и `dark` допустимы `promo`, `promo-muted`, `promo-pale`, `promo-vibrant`. Для них действует общий состав состояний.

Секция `static_promo` разрешает только `default`. Варианты `_inverted` не предусмотрены.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
