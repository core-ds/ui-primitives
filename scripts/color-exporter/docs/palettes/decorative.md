# Decorative

Страница `colors_decorative.json`; [модуль](../../src/palettes/decorative.mts).

Режим — `light` или `dark`. Семейства: `decorative`, `decorative-soft`, `decorative-muted-alt`, `decorative-muted`, `decorative-text`. У каждого возможен суффикс `_inverted`.

Во всех секциях `decorative-text` и во фреймах с точными именами `red` или `yellow` разрешён только `default`. Остальные фреймы используют общий состав состояний.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
