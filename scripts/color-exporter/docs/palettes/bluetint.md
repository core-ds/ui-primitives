# BlueTint

Страница `colors_bluetint.json`; [модуль](../../src/palettes/bluetint.mts).

Допускаются секции `light/<семейство>`, `dark/<семейство>`, `static_<семейство>`. Семейство состоит из строчных букв, цифр, дефисов и подчёркиваний; вложенные сегменты через `/` запрещены. Возможен суффикс `_inverted`.

Состав состояний общий: любое непустое упорядоченное подмножество `default`, `hover`, `press`.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
