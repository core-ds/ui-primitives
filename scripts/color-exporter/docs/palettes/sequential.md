# Sequential

Страница `colors_sequential.json`; [модуль](../../src/palettes/sequential.mts).

Секции: `light/sequential-<имя>` или `dark/sequential-<имя>`. Имя состоит из строчных букв, цифр и дефисов. Настоящее состояние — только `default`.

Статические и `_inverted` секции не предусмотрены.

[Общий алгоритм, заполнители и формулы полей](../FIGMA_FORMAT.md).
