## Что упрощено

- Повторные проверки уже рассчитанных внутренних объектов заменены типами TypeScript. Проверки данных на входе — Figma, прежний JSON, Git и ответы GitHub — остались.
- Вместо нескольких фабрик и служебного реестра — общий алгоритм и десять коротких настроек. Модуль ищется по имени обнаруженной страницы; для новой стандартной страницы он не нужен.
- Идентификаторы и поля строятся непосредственно при обходе дерева. Убраны промежуточные представления токена и повторная нормализация результатов.
- GitHub-обвязка стала одним последовательным сценарием. Убраны отдельные слои подготовки отчёта, проверки его формы и русских числительных. Описание реквеста содержит изменённые файлы, конкретные устаревшие ключи и ссылки на документацию.
- Большие JSON-снимки, утилита их генерации и подключение внешнего эталона удалены из поставляемого дерева. Сравнение с прежними результатами было проверкой перехода; постоянные тесты самодостаточны. Прежняя версия и данные сохранены в резервной копии.
- Тесты объединены в таблицы и сценарии с настоящими временными Git-репозиториями. Вместо множества проверок подменяемых внутренних функций проверяется результат работы инструмента.
- Сборка очищает только `dist/color-exporter` перед компиляцией: удалённый модуль набора не остаётся действующим в старой сборке.
- Документация сведена к общему алгоритму, тематическим инструкциям и отдельным карточкам наборов. Повторяющиеся документы удалены, прежний файл черновика оставлен ссылкой на актуальные правила.

## Последний пересмотр: 963 → 942 строки

- В `action.mts` ручной разбор нескольких форматов Git заменён точным сравнением ожидаемых и фактических записей индекса: путь, тип/права и стадия разрешения конфликта. Убрана повторная регулярная проверка пути; используется общий `TARGET`. Режим файла в основе читается один раз и запоминается. Модуль сократился со 146 до 131 строки.
- В `sync.mts` устаревшие записи сразу добавляются после активных. Прежний JSON уже обходится в нужном порядке, поэтому отдельная коллекция и её повторная сортировка не нужны. Сохранены проверка старых значений и положение поля `deprecated`. Модуль сократился с 39 до 35 строк.
- В `layout.mts` общая часть имени рассчитывается один раз на секцию. Для состояния остаётся собрать окончательные поля. Проверки по-прежнему выполняются в контексте конкретного прямоугольника, чтобы ошибка содержала его путь и `id`. Это оптимизация повторной работы, а не сокращение строк: модуль вырос со 100 до 104 строк.
- Добавлены два случая именования и проверка сохранения режима `100755` после обновления основы ветки. После удаления условной проверки полного эталона осталось 20 самостоятельных групп; тесты занимают 352 строки вместо исходных 358.
- Позднее пример постороннего файла с пробелом в имени заменён на `README.md`. Проверки отказа, неизменности удалённой тестовой ветки и отсутствия обращений к GitHub сохранены. Рабочая защита разрешённых путей не менялась.

Из рабочего кода убраны 15 строк, тесты сократились на 6 строк. Ориентир в 700 строк не достигнут. Отдельный временный индекс Git и объединение остальных модулей не приняты: они добавляют служебную работу либо лишь перемещают существующий алгоритм. Безопасная запись и проверки чужих изменений не упрощались ценой изменения поведения. Правила наборов, сборка, зависимости, командная строка, транспорт и GitHub Actions в последнем проходе не менялись.

## Что сохранено и проверено

При проверке перехода все десять палитр совпали с прежними результатами побайтово: **2057 активных и 232 устаревших токена**. Ранее выполнены **50 сравнений старого и нового алгоритмов**: десять палитр в пяти сценариях — исходные данные, новый токен, исчезнувший токен, изменённый цвет и переставленные секции/фреймы. Это результаты приёмки переработки, а не зависимость обычного запуска.

Постоянные тесты проверяют формулы пяти полей, особенности наборов, любые непустые сочетания состояний, игнорирование `empty`, стили и переменные, коллизии, порядок и устаревание, новые страницы, отсутствие частичной записи при ошибке данных и повторяемость.

Отдельно проверены файловый откат, сохранение чужой правки при невозможности отката, резервные копии, права файлов, запрет ссылок, а также повтор после успешной отправки и сбоя создания реквеста, исчезнувшие страницы, обновление основы ветки, посторонние пути и изменение коммита хуком.

Дополнительная разовая проверка на пяти изолированных Git-репозиториях подтвердила сохранение `100755`, создание нового файла с `100644` и отказ при трёх изменениях: `100644 → 100755`, `100755 → 100644`, новый файл с `100755`. При отказах удалённая тестовая ветка не менялась и клиент GitHub не вызывался. Это отдельная выполненная проверка, не пять дополнительных постоянных тестов.

При независимом разборе найден и исправлен крайний случай: разовая ошибка чтения сразу после успешной замены больше не блокирует восстановление исходника. Идентичность установленного файла сохраняется до контрольного чтения; есть отдельный тест.

Перед публикацией проверка типов TypeScript и три существующих SVG-теста через Mocha прошли повторно. Производственные `styles/`, `package-lock.json` и `tsconfig.json` не изменены. Общий `npm test` ранее не запустился из-за запрета старому измерителю покрытия создавать временную папку в домашнем каталоге; перед публикацией он не повторялся.

Принудительные процентные пороги убраны из workflow; измерение покрытия осталось отдельной командой. Совместимость подтверждается выполненными сравнениями и сценариями, а не обещанием проверки всех возможных входов.
