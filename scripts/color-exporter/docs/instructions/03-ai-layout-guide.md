# Инструкция для ИИ: собрать раскладку цветов

Создай или обнови раскладку в [Color Exporter](https://www.figma.com/design/JGR9GpDXUneyYHfDdb7BDT/Color-Exporter) по данным библиотек Figma и правилам ниже. Обозначения в квадратных скобках определены в [глоссарии](01-general-rules.md#глоссарий): подставляй реальные имена, не создавай слои со скобками. Результат — страница с образцами, связанными с исходными переменными или стилями. Исходные библиотеки используй для чтения и привязок; изменения вноси только в раскладку.

## 1. Установи источники

До сборки определи целевую страницу `colors_[набор].json`, выбранные библиотеки и коллекции, режимы, переменные или стили образцов и подложек секций. Сначала используй доступные ссылки и контекст; уточняй только то, что установить не удалось.

Состав, имена и значения цветов бери из выбранных библиотек Figma. Недоступный источник не равен отсутствующему токену: остановись и уточни доступ, не заменяй его похожим цветом.

## 2. Определи состав раскладки

Работай только с выбранным `[набор]`:

1. Выпиши из Figma его `[семейство]` и входящие в каждое семейство `[токен]`.
2. Для каждого токена определи имеющиеся `[режим]`, `[состояние]` и `[inverted]`.

Создавай все существующие в источнике сочетания по общим правилам. Новое семейство, стандартное состояние или `[inverted]` не требует отдельного правила для набора. Если имя источника нельзя разобрать общим алгоритмом или [особенностями набора](#особенности-наборов), уточни его смысл до сборки; не пропускай и не переименовывай токен.

## 3. Разбери имена

В схемах с состоянием в конце пути `[состояние]` = `hover` или `press`; без него используется `default`.

Для `[режим]` = `light`/`dark`:

```text
[семейство][inverted]/[токен] + [режим]
→ секция [режим]/[семейство][inverted] → фрейм [токен] → default

[семейство][inverted]/[токен]/[состояние] + [режим]
→ секция [режим]/[семейство][inverted] → фрейм [токен] → [состояние]
```

Для `[режим]` = `static`:

```text
static_[семейство][inverted]/[токен]
→ секция static_[семейство][inverted] → фрейм [токен] → default

static_[семейство][inverted]/[токен]/[состояние]
→ секция static_[семейство][inverted] → фрейм [токен] → [состояние]
```

`[inverted]` добавляй при наличии модификатора в источнике. Других модификаторов нет.

`[семейство]` — весь путь перед именем токена, без служебного префикса `static_` и конечного `[inverted]`. Вложенные `/` остаются в имени секции. Сохраняй исходные дефисы, подчёркивания и `[inverted]`.

В `[токен]` допустимы строчные латинские буквы, цифры и дефисы; в `[семейство]` — также подчёркивания и `/`.

Конечные `hover`/`press` означают состояние только при такой структуре исходной библиотеки: слово `hover` может быть именем самого токена. Неоднозначное разделение согласуй до сборки. Базовому значению назначай прямоугольник `default`, не дописывая `/default` к имени источника.

Для каждого образца сохрани вне макета: исходный идентификатор, точное имя, коллекцию и её фактический режим; затем `[набор]`, `[режим]`, `[семейство]`, наличие `[inverted]`, `[токен]`, `[состояние]` и полученное имя `[секция]`. Проверяй идентификатор и библиотеку, а не только совпадение имени или цвета.

## 4. Собери дерево и привязки

Страница → секции → фреймы → прямоугольники. Никаких дополнительных контейнеров, подписей, картинок или экземпляров компонентов. Имена секций уникальны на странице, фреймов — внутри секции. Пустые секции и фреймы не создаются.

У настоящего образца ровно одна заливка: видимая, `SOLID` (сплошная), связанная с исходной переменной или стилем. Дополнительные заливки, включая скрытые, запрещены. Не подставляй HEX и не создавай локальные копии библиотечных токенов. Сохраняй исходную прозрачность; не уменьшай прозрачность узла или родителей для оформления.

Задай режимы **каждой** участвующей коллекции, включая отдельные коллекции состояний и подложки. Режимы закрепи на секции; проверь отсутствие случайных переопределений в потомках. Идентификаторы режимов получай из соответствующей коллекции. Статический токен не дублируй как светлый и тёмный.

## 5. Выровняй состояния

В каждом фрейме состояния идут сверху вниз: `default`, `hover`, `press`. Создавай только существующие в источнике состояния.

Для всей секции найди последнее существующее состояние и оставь строки от `default` до него. Пропуск в строке заполни прямоугольником `empty` без заливки, обводки, эффектов и привязок:

```text
Есть default и press → default, empty, press
Есть только press   → empty, empty, press
В секции только default → одна строка, без лишних empty
```

В каждом фрейме остаётся хотя бы одно настоящее состояние. Прозрачный токен с привязкой не заменяется на `empty`.

## 6. Размести секции

- Образцы и `empty`: **100 × 100 px**.
- Фрейм токена: вертикальный Auto Layout, без заливки, отступов и промежутков, размер по содержимому.
- Фреймы в секции: слева направо, без промежутков; поля секции — **100 px**. Для `N` токенов и `K` строк размер секции — `(200 + 100 × N) × (200 + 100 × K)`.
- Семейства образуют столбцы. Строки сверху вниз: `light`, `light_inverted`, `dark`, `dark_inverted`, `static`, `static_inverted`. Это обозначения строк сетки, не имена секций. Отсутствующую у всех семейств строку не резервируй.
- Между столбцами и строками — **64 px**. Следующий столбец начинается после самой широкой секции текущего столбца; следующая строка — после самой высокой секции текущей строки. Секции одной строки имеют одинаковый `Y`, но сохраняют собственную высоту.
- Сохраняй порядок семейств и токенов существующей страницы. Для новой используй порядок библиотеки; неоднозначный порядок согласуй.
- Подложка — согласованная переменная или стиль на самой секции, без фонового прямоугольника и скруглений. Не выбирай произвольный HEX.

## 7. Проверь и передай результат

При пересборке сначала проверь новую раскладку на отдельной рабочей странице. Заменяй только согласованный набор узлов; посторонние материалы не удаляй и не перемещай без согласования.

Сверь в обе стороны: каждому запланированному токену, режиму и состоянию соответствует один образец, каждому образцу — реальный источник. Проверь имена, привязки, фактические режимы, число заливок, порядок состояний и отсутствие лишних узлов. Цвет образца должен совпадать со значением исходной переменной или стиля в выбранном режиме.

Посмотри каждую секцию в читаемом масштабе и страницу целиком: нет пересечений, обрезанных образцов, смещённых строк и лишних полей.

Передай ссылку на страницу, количество настоящих образцов и перечень оставшихся расхождений с источниками Figma или правилами раскладки.

## Особенности наборов

### X5

**Особенность:** в общих статических схемах используй префикс `static/` вместо `static_`. Имя секции — `static/[семейство][inverted]`; состояния и `[inverted]` обрабатываются по общим правилам.

**Пример:** `static/brand/primary` → секция `static/brand` → фрейм `primary` → `default`.
