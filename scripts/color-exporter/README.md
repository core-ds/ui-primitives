# Экспорт цветов из Figma

Экспортёр преобразует страницы `colors_*.json` файла Color Exporter (`JGR9GpDXUneyYHfDdb7BDT`) в одноимённые JSON в `styles/`. Страницы Figma определяют состав наборов. Новая стандартная страница подключается автоматически; отдельные файлы описывают только отличия известных наборов.

Все выбранные страницы рассчитываются и проверяются до записи. Активные токены получают пять полей: `rgba`, `hex`, `figma`, `web`, `alias`. Исчезнувшие токены сохраняются в отдельном хвосте с `deprecated: true`. Возвращённый токен снова становится активным.

## Локальный запуск

Требуется Node.js 24. Команды выполняются из корня репозитория:

```sh
npm ci
npm run test:colors
npm run sync:colors -- --repo-root /path/to/repository --figma-json /path/to/figma-rest.json --check
```

`--repo-root` обязателен; внутри должна существовать настоящая папка `styles`. `--figma-json` принимает полный сохранённый ответ Figma REST с `document.children`. Для такого запуска секреты не нужны. Чтобы получить свежий ответ REST, задайте переменную окружения `FIGMA_TOKEN` и пропустите `--figma-json`.

`--check` выполняет полный расчёт без записи: код завершения `0` означает отсутствие изменений, `2` — наличие изменений, `1` — ошибку. Для записи повторите команду без `--check`. Локальный запуск не выполняет Git-команд и не создаёт запросов на слияние.

Без `--palette` обрабатываются все экспортные страницы. `--palette bluetint` выбирает один набор; для `colors_new_palette.json` имя параметра — `new-palette`. Если выбранной страницы нет, запуск завершается ошибкой. Повтор параметра и неизвестный параметр тоже считаются ошибками.

Результат в терминале содержит путь файла, признак изменения и ключи, впервые получившие `deprecated: true`. Основой локального расчёта служат текущие JSON. Для записи используйте отдельную копию репозитория: [границы защиты файлов](docs/FILE_WRITES.md).

## Проверки

`npm run build:colors` удаляет только прежний `dist/color-exporter` и запускает сборку TypeScript. Очистка нужна, чтобы удалённое особое правило не оставалось в готовой сборке. Команды проверки и экспорта автоматически выполняют эту сборку перед запуском.

`npm run test:colors` запускает проверки преобразования, файловой записи, командной строки, HTTP и Git. Git-проверки используют временные локальные репозитории и подмену ответов GitHub.

`npm run test:colors:coverage` дополнительно выводит покрытие кода; обязательного процентного порога нет. Все тесты самодостаточны: данные создаются внутри проверок, внешние снимки и секреты не нужны.
